## Что сделать
1. Банк: F01–F10 из PR 519 (регрессия) + новые семейства **RU→DE** по Вихерту (1975) и Albinus (только реально импортированные страницы — проверить fetch по source/page) — не меньше 10 RU→DE семейств; 3–4 **DE→RU** (немецкий вопрос к Гаузе/Трауготту); 4 отрицательных. Gold — по фактически принятому тексту (fetch), до прогона; исполнитель поиска не видит gold (роли — ПМИ §3; при одном исполнителе — честно отметить ограничение).
2. Политики (ПМИ §6, PR 515 §12.1): V0 один запрос на языке вопроса; V1 смешанная строка; V2 RU и DE отдельно; V3 два запроса одного языка; V4 адаптивный (первый как V0 → чтение → один шаг по пробелу: scope книги / соседние страницы / запрос на другом языке). Отдельно: короткая (§10.2) против полной (§10.1) инструкции на V4.
3. Для каждого: полнота доказательного набора в top-3 и в объединении, ответ (полный/частичный/неподтверждённый), полнота цитат, число вызовов, время search/fetch (wall и backend). Бюджет: ≤ 120 search, ≤ 80 fetch, P=1, последовательно.
4. Сохранить вывод анализатором `scripts/benchmarks/rkb_cascade_pilot_summary.py` (ветка PR 519) и опубликовать агрегаты в docs-only draft-PR (тексты книг и gold — только приватно, как в PR 519).
5. Итог: таблица по стратам RU→RU / RU→DE / DE→RU, рекомендованный **текст инструкции** (одна для Full MCP и Миры) с обоснованием; если различия не видны — так и сказать.
