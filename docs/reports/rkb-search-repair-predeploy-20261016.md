## Проверки источников и существенных утверждений

- **Кнайпхоф, основание собора.** Собственный фрагмент активной редакции книги Гаузе по печатному развороту/физической странице 8 подтверждает, кто начал строительство и намерение построить укреплённый храм. Найден через отдельное ограниченное чтение источника, **не** через успешный natural-query top-8.
- **Сваи собора.** Отдельный связный фрагмент того же действующего оригинала объясняет мокрый грунт, свайные основания строений и особую трудность строительства собора. Короткий exact excerpt старой карточки теперь подкреплён чтением окружающего контекста; это *сообщение Гаузе*, а не независимая археологическая экспертиза.
- **Арбитраж 1246 года.** Контекст Гаузе говорит об арбитраже, роли Ордена и основании города. Контекст Бруннека — о пожаловании земли любекцам и нормах Кульмского права. Оба авторизованных источника прочитаны по исходным страницам; второй не является дословным подтверждением всех слов редакционного заголовка первого. Авторитетное `sources_page` содержит обе книги — представление не потеряно.
- **Старый B3** как точный сохранённый тестовый `fetch` не восстановлен: новый просмотр другого свидетельства не выдаётся за replay отменённого B3.

В открытом репозитории оставлены только безопасные описания и измерения. Не публикуются document/chunk/story UUID, оригинальные excerpts, удостоверения, private URLs, page images и полные трассы.

## Точное продолжение после полномочий на развёртывание

Выпустить фиксированный CI-проверенный SHA из PR #122 штатным существующим deploy path с consistent SQLite backup и безопасным откатом; подтвердить фактический deployed SHA MCP/indexer; дождаться ограниченного, наблюдаемого backfill `story_outbox` без массового импорта. С тем же actor scope повторить исходный semantic story query и gold natural book query (не подменяя текст вопроса), прежние шесть семейств и несколько независимых negative/cross-language случаев. Зафиксировать ответ, исходный proof, статусы ready/partial/degraded, latency backend/MCP wall, успешность первых попыток. Если gold не появился в top-5/8, оставить **FAIL**, не называть source CI продуктовой приёмкой.

Следующую книгу можно испытывать отдельно в bounded scope по [действующей ПМИ](../testing.md), но это не подтверждает mass-ingestion readiness и не закрывает текущий дефект поиска.
