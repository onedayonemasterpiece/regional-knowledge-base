## Как мерить страницы без RKB MCP

У этой сессии RKB MCP отвалился, нужен повторный вход владельца (`/mcp` → rkb). Он и не нужен: ответ `chatgpt_task_status` на book_task_id содержит блок `book_task` с полями accepted_pages, next_cursor, last_operation_at, activity_state, current_book_index/total_books.

Снимок всех задач: `python3 -I docs/handoffs/rkb-import-books-snapshot.py <book_task_id…>`. Скрипт дописывает строки в `~/rkb-import-snapshots.jsonl` (путь меняется через `RKB_SNAPSHOTS`). Прирост считай по двум снимкам.

`chatgpt_start` на книгу с активной задачей отклоняется («already has an active book task»). Второго читателя так не создать. После отдыха лаунчер продолжает задачи сам.
