# Проверка «Читать первоисточник» — PDF P0 и озвучка P1

2026-10-26, обновлено по прямому решению владельца. **План приёмки, не доказательство готовой реализации.** [Спецификация](../designs/rkb-source-unit-pdf-and-audio-20261026.md).

Тестировать на синтетических и разрешённых владельцем образцах без коммита приватных страниц, книг, аудио, секретов или URL. Закрытая группа РКБ, договорные права — вне программы. Для тестов не вводить новую лицензионную БД, per-book export grants, UI или посредник передачи файла через DevCoveer. Живой Kaggle — только по существующему owner/Шкипер-порядку.

## P0.A — структурные единицы **на импорте**

| ID | Сценарий | Успешный результат |
|---|---|---|
| I01 | Модель читает 3–4 страницы главы обычным `book_ingest` | Вместе с accepted pages сохраняются chapter/article title и точный start anchor; unit остаётся open до подтверждённого завершения |
| I02 | Следующий импортируемый пакет начинается с новой главы | Предыдущая глава закрывается точным end anchor, не требует нового вызова модели при PDF-экспорте |
| I03 | Статья A заканчивается и статья B начинается **на одной странице** | Границы определяются конкретными source region/span, а не номером страницы; A не захватывает B |
| I04 | Конец главы совпадает с концом книги | Завершается при проверенном EOF/finalize; нет искусственно выбранного количества страниц |
| I05 | Конец главы пока неизвестен / страница непринята | Текст уже принятых страниц ищется в RKB; PDF этой главы сообщает `unit_not_ready`, не выдаёт частичную главу за полную |
| I06 | Исторический импорт без границ | Нет model-on-demand при экспорте; при необходимости границы восстанавливаются в обычном процессе reprocess/stage |
| I07 | Один source span сопоставлен с существующей article identity | Переиспользуется существующий scope/article ID, нет параллельного каталога единиц |
| I08 | Заголовок в середине region, сноска через соседнюю страницу | Единица включает точные принятые фрагменты в исходном reading order, без пропуска/дубликата |

Выгрузка одной главы должна быть **детерминированной** из сохранённого исходного текста и структуры. Семантические BGE chunks и ответ модели нельзя использовать как replacement author text.

## P0.B — PDF

| ID | Сценарий | Успешный результат |
|---|---|---|
| P01 | Цитаты 1 и 3 относятся к одной главе | По фразе пользователя модель вызывает MCP, формируется **один PDF одной главы** |
| P02 | Цитаты принадлежат двум статьям | Каждая статья возвращается отдельным PDF, без выдуманного общего издательского сборника |
| P03 | Русский текст с «ёлка», №, тире, дореформенными и нестандартными символами | Копируемый PDF сохраняет исходные символы и знаки; нет пропущенных глифов |
| P04 | Немецкий текст: ä, ö, ü, ß и имена мест | Корректный шрифт/ToUnicode, неизменный исходный текст |
| P05 | 2, 10 и 30 страниц + длинный абзац | Читаемая A4-вёрстка, красная строка, нормальные поля, отсутствие сиротских заголовков и нечитаемых переносов |
| P06 | Заголовки, примечания, маркированный список и таблица | Точный текст и порядок; неподдержанная важная структура — явная ошибка, не молчаливое удаление |
| P07 | ISBN, УДК, ISSN, ББК и DOI в подтверждённых сведениях | Печатаются верные значения **конкретного издания**; отсутствующие реквизиты не выдумываются |
| P08 | Исходный номер страницы не равен номеру созданного PDF | Обе системы нумерации не смешиваются; на первой странице указан источник |
| P09 | Встроенный PDF-паспорт | «База знаний региона Калининградская область», библиографические данные, заголовок единицы, исходные страницы |
| P10 | Глава завершена, но источник withdrawn или actor не состоит в допущенной группе | Действующий source/actor gate отказал; **нет новой системы юридической проверки лицензий** |

Проверять по фактическому принятым region/span текстам, а не только сравнением общего числа слов, скриншотами вёрстки или успешным вызовом PDF library. Подтвердить оригинальные строковые значения и реальный readable PDF.

## P0.C — передача и асинхронность

| ID | Сценарий | Успешный результат |
|---|---|---|
| D01 | MCP start/status/get в модели | По готовности **реальный PDF** поступает клиенту непосредственно из Kaggle, не через скачивание/копирование PDF-байтов на Dev |
| D02 | Slack-клиент инициирует тот же сценарий | Работа через текущий Slack→MCP контур, без нового веб-приложения или визуального выбора цитат; результат доступен через реально поддерживаемую каналом доставку |
| D03 | Прямой PDF-контракт на конкретном MCP клиенте | Не считать `ImageContent` для картинки доказательством поддержки PDF. Проверить его фактический file/resource transport, MIME, размеры и получение моделью |
| D04 | Повтор того же запроса, разрыв и восстановление связи | Возобновляется существующая операция, не генерируется лишний PDF; понятный статус |
| D05 | Параллельные PDF и обычный тёплый поиск | Экспорт вне hot path, существующие p95/latency и контроллер Kaggle не сломаны |
| D06 | Готовая операция без подтверждённого файла | `ready` не объявляется до фактической доступности PDF через вызывающий клиент |

## P1 — озвучка (позже)

| ID | Сценарий | Успешный результат |
|---|---|---|
| A01 | Проверка существующего Wonderful Lections Qwen3-TTS Kaggle runner | Подтверждённый long-form MP3, нет слепого запуска второго runner при временном 429 |
| A02 | RU/DE главы разной длины через Qwen и более быстрый TTS | Измерены cold/warm start, время полной генерации, RTF, точность топонимов и отсутствие пропусков |
| A03 | Прерывание после нескольких готовых аудиофрагментов | Готовое аудио хранится в обычном private versioned Kaggle Dataset, повторное задание использует уже успешные результаты, если точный исходный текст/голос совпадают |
| A04 | Старые audio versions за пределами retention дней/недель | Удалены штатными Kaggle dataset-операциями по правилу срока хранения; свежий результат не потерян |
| A05 | PDF готов, TTS Kaggle занят или недоступен | PDF доступен независимо; аудио сохраняет отдельную ожидающую операцию |
| A06 | Audio завершён | Модель получает реальный аудиофайл из Kaggle, а не копию на Dev |

**Критерий готовности P0:** полный реальный MCP путь «цитата → сохранённая при импорте глава → PDF → модель» проходит и показывает читаемый PDF. Зеленые unit tests без получения файла моделью не равны реализации. Критерий готовности P1 — успешный полный длинный аудиофайл, не heartbeat/частично собранный MP3.
