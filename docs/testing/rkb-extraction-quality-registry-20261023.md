Для случаев с идентифицированным настоящим printed page сохранять оба соседних page refs, реальный span/region и source edition. Не копировать одинаковое предложение в оба chunks как две подтверждённые находки. Поверх `passage_ref` могут быть `continuation_ref` и figure proof IDs только после actual import, без самостоятельного построения фиктивных UUID. Отдельная safety матрица не должна подмешиваться к статистике исторической точности.

## 4. Заморозка, separation и двухступенчатая adjudication

**Independent original-needed oracle (отдельно от retrieval gold):** до freeze два рецензента читают те же immutable original pages/sections *вне* RKB `fetch`, размечают факты, ожидаемые Story/facts_only, отрицания и page/span. Затем сверяют их с accepted text и фактически сохранёнными Story/facts_only: пропуски импорта/извлечения остаются **original-based omissions** в coverage denominator, даже если `fetch` их не выдаёт. `fetch` измеряет retrieval *после* extraction, а не полноту original→storage. Если original недоступен — `ORIGINAL_NEEDED`, completeness gate **NOT ESTABLISHED**, а не zero/MISS/PASS. Публичные Wikipedia/Wikisource fixed originals из §2 пока лишь proposed fixture candidates: для retrieval scoring допустимы **только после фактического owner-approved import + source/page/accepted passage mapping**. Gause0–10 receipts не означают полный book import.

**Preflight corpus** — только когда Шкипер **завершит** все выбранные imports (книги или несколько статей допустимы), подтвердит original intake/license/source edition hash, exact native accepted source revision, manifest страниц/region/passages, BGE vector/projection readiness, current ACL и withdrawal, available retrieval methods, restored/served runtime SHA. Исходные public files здесь — **proposed** fixture candidates, они *не импортированы этим ПМИ*. До source mapping запрещён оцениваемый retrieval. Нужен ≥3 независимых реальных произведения/статьи, минимум один RU и один DE, ≥30 реально eligible независимых held-out families, representative+challenge, native RU/DE и обоснованные cross-language; невозможно — честный `BATCH_BLOCKED_SOURCE`, не выдуманный PASS.

**Freeze manifest до первого run:** exact repo/installed code SHA, SQL schema+functions versions, dataset/PG active cursor, source IDs+SHA+edition+rights/licence+ACL/filter, page/region/accepted passage mapping, tokenizer/BGE-M3 checkpoint/dim/quantization, embeddings/index/projection versions, candidate budgets, neighbor flags, query/prompts, concurrent load, cache/warm, model/client version, grading rubric, family definitions and `gold_manifest_sha256`. Издать immutable `batch_id`, signer/reviewer и freeze timestamp; **там же закрепить** порядок/наименование файлов результата и run/attempt IDs из существующих native logs, чтобы семиполевая схема оставалась однозначной для всех variants/arms/repeats без нового harness. **Два рецензента** независимо проверяют gold по оригиналу (для Wichert при визуальной сомнительности — scan); при расхождении — явно `disputed` + третье решение **до открытия held-out результатов**. Нельзя «исправить истину», увидев неудачу модели; post-freeze изменение — новая `gold_version` и полный новый batch.

**Blinded execution:** другому ChatGPT окну на каждый bounded набор дать **только** `case_id`, RU/DE **вопросы**, разрешённый corpus/source scope, tools, frozen parameters/budget; **не давать** `minimal_answer`, anchors, rationale, категории с подсказкой, сопоставление с ответами других окон и gold-файл. Осторожно с доступом GitHub: явно запретить чтение `docs/testing/rkb-extraction-quality-cases-20261023.jsonl`, иначе blind недействителен; можно передать question-only packet. Исполнитель возвращает фактически полученный answer/evidence refs и timestamps, а exact native tool calls/IDs/ranks/errors сохраняются в существующих provider logs, доступных по frozen manifest **вне компактной result row**; **сам себя не оценивает** (`verdict.adjudication="unreviewed"` до judge). Для EQ26-075/076 читать **только фактически** сохранённые Story body/facts_only штатными авторизованными read-интерфейсами (без записи/нового сочинения): exact текст через `answer.text_ref`, source/revision/page/passage через `evidence_refs`. Missing body/facts — `answer.text_ref=null` и отсутствие refs, не новая Story/пересказ. Приватный body и трассы остаются под первоначальным ACL; в PR только safe refs/hashes.

**Append-only:** отдельная неизменяемая строка compact-result JSONL на каждую запланированную попытку; `verdict.execution` = `NOT_RUN/completed/timeout/denied/error/pending/unknown/terminal_unresolved`, `verdict.adjudication` = `NOT_RUN/unreviewed/…` до независимой оценки. `unknown` не превращать в MISS и не считать terminal; исход/класс ошибки, границы timeout и native operation/trace IDs уже фиксируются штатным логом и freeze manifest, **не** новыми полями JSONL. Не удалять неудачи/не перезаписывать строки `case_id`, frozen gold, порядок попыток или таймер. Повтор после неизвестного эффекта — только штатный readback исходного operation ID, не новый независимый call. Окна остаются слепыми друг к другу.

**Одна аналитическая точка:** до конца *всех* источников, arms, заблокированных/errored попыток и predeclared repeats **нет** структурных правок, SQL, re-chunking/re-import, модификации prompts/weights по одиночной неудаче; только raw outcome. Batch **`EXECUTION_COMPLETE`** только если frozen manifest сверяет **каждую** `eligible family × query-variant × method × neighbor arm × repeat` со своим append-only `verdict.execution` terminal (completed/error/denied/timeout или terminal_unresolved с проваленным gate) и сохранённым native trace; **rubric ещё не нужна**. `pending/unknown/NOT_RUN` не закрывают матрицу и не исчезают из denominator. При изменении corpus — новый batch, даже если кейсы совпадают.

**После `EXECUTION_COMPLETE` и raw-output freeze:** два независимых оценщика проверяют `answer.text_ref` и `evidence_refs` против отдельно вычитанного неизменяемого **оригинала**, только затем gold unseal; итоговая рубрика записывается в `verdict.adjudication`, релевантность source evidence в `hit_at_k["5"/"10"]`. Разрешить disagreements, зафиксировать family taxonomy; только **вся** reviewed/settled eligible матрица получает **`ADJUDICATION_COMPLETE`**. До неё нет общего quality verdict или рекомендаций менять storage. Затем единый multi-source root-cause report (source absent/transcription/page-boundary/translation/ANN/filter/fusion/neighbor/model/ACL/timing), Product решает улучшение, Opus назначает source/storage change/review, Шкипер организует **отдельно разрешённый** reimport. Старые runs/source/gold pins неизменны, новые versions + полный frozen multi-source paired rerun; иначе причинность не доказана.

**EQ26-075/076, rubric содержания/provenance:** `EQ26-075` требует точный реально сохранённый `Variant.body` или explicit absence: источниковые участники, действие, исход, продолжение, неопределённость, без придуманных мотивов и с attribution. `EQ26-076` требует **фактически извлечённые** `facts_only` по должностям и функциям, а **не** новую Story. Проверять смысл и точные source/revision/page/passage refs отдельно от retrieval и original→storage полноты; yes/no не ответ. Только `answer.text_ref`, `evidence_refs`, `verdict` из компактной схемы + независимая исходная рубрика, **без новых полей/harness**.

## 5. Arms, бюджеты, парность и производительность — ВСЕ NOT RUN

Взять точно методы [PR351](../audits/rkb-crosslanguage-search-decision-20261023.md): configured baseline, BGE-only, lexical-only, configured fusion, условные клиентский RU+DE запрос, historical aliases, BGE sparse, ColBERT rerank, cross-encoder и derived import-time translation, **только реально существующие/разрешённые runtime arms**. Не записывать отсутствующую ветку как 0 ms/PASS. Компонент rerank оценивать лишь при наличии source-relevant кандидата в first-stage set (candidate recall@100). Сравнивать ANN vs exact vector на том же source scope, не маскировать dense провалы lexical-предфильтром.

В рамках **того же** frozen held-out для каждого applicable retrieval arm три orthogonal соседних режима из **чужого** addendum PR351: **(N0)** нет соседей; **(N1)** только сильное continuation по **existing** legacy `continuation_context.py` (если native контракт действительно совместим, иначе `NOT IMPLEMENTED`); **(N2)** всегда ±1. Не строить новые контракты/регистры. Зафиксировать исходный ranked evidence + добавленные refs; один source/revision/ACL/withdrawal check на **каждого** соседа, no duplicate, wrong neighbor/noise и смысловую полноту на verified page-boundary. Это *план* — ни одного вызова нет.

**Pre-registration budgets:** minimum frozen 30 independent families, planned larger registry 59; rank `K=5/10`, candidate@100 (или фактически max≤100, иначе unavailable), одна и та же длина/язык/парафраз source scope, topK, candidate cap, tokenizer, chunk set, prompt/model, parameter settings across paired arms; для rerank K=10/20/50 только заранее выбранные comparators. Randomized/alternating AB order; warm/cold, cache hit/miss, no-parallel/4 user и concurrent import записывать отдельными стратификациями, не смешивать. Для preliminary устойчивого p95 план ≥200 *завершённых или явно завершившихся ошибкой* user attempts **на вариант** плюс независимая вторая серия (это **не** 200 successes). Если столько не проведено, показывать p95 как описательную оценку с N и CI, gate `NOT ESTABLISHED`. Не переписывать benchmark weights по held-out.

**Quality (по family, не по перефразировкам):** отдельно (A) полнота immutable original→accepted extraction→Story/facts (отсутствующий в `fetch` оригинальный факт остаётся в denominator) и (B) retrieval для eligible evidence. Первый компактный результат содержит только `hit_at_k["5"]`/`["10"]` после независимого review и `verdict`; MRR@10, candidate@100, provenance/family taxonomy, precision/coverage/abstention/noise/neighbor оценки требуют frozen gold + существующие native traces и **не притворяются уже заполненными колонками** первичной schema. Для critical RU→DE Hit@10 отдельный slice. Protected handoff thresholds **неизменны**: dense-only Hit@5≥85%, Hit@10≥90%, critical RU→DE Hit@10≥85%. Ineligible/absent original source — block, не search MISS; true negative в eligible frozen corpus проверяется по честной abstention.

**Time end-to-end and per stage:** первый компактный прогон записывает два наблюдённых полных clock в `latency_ms.user_to_evidence` и `latency_ms.user_to_answer` (включая модельную генерацию, tool/queue/client ожидание); недоступное значение `null`, без выдачи backend-only числа за user latency. Дополнительные `T_public_MCP`, `T_backend_ranked`, stage breakdown, отдельный `T_user→full answer`, cache/warm, p50/p95/paired deltas и confidence анализируются **только после полного blind batch** из уже существующих телеметрии/trace clocks и frozen manifest, при фактической доступности. Protected warm backend p95≤1000ms, public MCP p95≤1500ms, interaction evidence deadline 2000ms **не** меняются и не считаются достигнутыми по одной первичной колонке.

**Cost/resource:** bytes/Unicode chars/BGE tokens original+adjacent passages, query/response tokens, tool calls, refs и wrong-neighbor noise, CPU/GPU/VRAM/RAM/I/O, SQL plan/buffers — **только если доступны в существующих native traces**, вне семиполевой строки первого прогона; `unavailable`/null не считать нулём и не заявлять пройденные gates. Состояния timeout/cancel/denied/degraded/pending/unknown входят в frozen attempts denominator; latency percentiles по observed с censored/failure rate и timeout budget, не по «быстрым» successes. Стоимость import/translation/rechunk/indexing/PG отдельно от per-query latency, после полного multi-source batch. По результатам первой компактной schema неполные resource gates помечаются `NOT ESTABLISHED`, а не фальшивый PASS.

## 6. Отбор, отказ и пределы достоверности

1. **Утверждения в фикшн и вторичной энциклопедии** — gold *внутри соответствующего документа*, а не верифицированный архивный факт. Текущий `source_verified_pending_second_adjudicator` **не** равен подписанному frozen gold.
2. **Статические статьи** допустимы вместо полных книг, но только после owner-approved import их фиксированных редакций и map к accepted source revision. В настоящем PR imports нет.
3. **Права** Википедии CC BY-SA и Wikisource/public domain/édition зафиксированы; media имеет собственные авторские права, нельзя считать весь вложенный файл свободным только по статье. Внешний публичный Gause 1994 не автоматически разрешён для републикации.
4. **Синтетика** проверяет refusal/scope/revision/prompt injection без реальных identity/grants/secret; ни одна synthetic запись не увеличивает `held-out` и не приравнивается к реальной «Истории».
5. Пока `accepted_passage_ref`, `source_page_id`, stage/saved и installed-runtime не получены от уполномоченного оператора, claims о source provenance ограничены публичной page/section, no pixels, no import quality proof.
6. Итог **NOT RUN** по всем retrieval/extraction/latency/CPU/GPU/resource/cost. Green docs validation не является импорта или production acceptance доказательством.
