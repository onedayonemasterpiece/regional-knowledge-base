# Задание RKB-Импорт R2: нельзя уйти дальше, пока предыдущая страница отклонена

Заказчик: RKB-Импорт (Claude). Владелец 29.10: импорт не должен молча пропускать страницы.

## Наблюдение (живое, Albinus)

Stage p59 принят (seq919), фаза text отклонена (seq920). Читатель продолжил: p60–64 приняты (batches 67–70). В книге осталась дыра на p59, её нашли вручную через сутки (Шкипер, import_timeline). Сервер это позволил.

## Код (main)

Найди, где native `stage` проверяет предыдущие пакеты (`kaggle_native_source_intake.py`, `stage` / `_state` / `rejected_batch_index`). После PR 600 `status` отдаёт страницу повтора отклонённого пакета, но новый stage следующей страницы при этом всё ещё принимается.

## Что сделать

Если в ingestion есть отклонённый и ещё не исправленный пакет, stage **другой** страницы отвечает отказом с кодом причины отклонения и `next_cursor` = первая страница отклонённого пакета (как status после PR 600). Исправленный stage той же страницы проходит как сейчас. Существующее поле `rejected_batch_index` / `rejected_reason`, без новых состояний.

**Важно (первая попытка, PR 613, закрыт):** отказывать при любом `rejected_batch_index` нельзя — тогда отвергается и исправленный повтор самого отклонённого пакета, и книга встаёт навсегда. Отказ только когда первая страница нового пакета ≠ первой странице отклонённого. Тест обязателен и должен реально запускаться, вывод — в PR.
