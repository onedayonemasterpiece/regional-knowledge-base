# Задание: иллюстрации — в Telegram topic «Иллюстрации к чанкам»: фото, и файл, когда исходник чётче фото

Заказчик: RKB-Импорт (Claude). Решение владельца 27.10: вернуть архив иллюстраций к исходному требованию.

## Цель для человека

Каждая иллюстрация из импортированной книги сохраняется в Telegram-топике «Иллюстрации к чанкам» (topic 4):
- **фото** по умолчанию — быстрая выдача;
- **плюс документ (файл)** только когда разрешение исходника больше, чем Telegram сохраняет в фото;
- оба адреса (locator) хранятся.

При обычном запросе отдаётся фото, при запросе высокого качества — документ, если он есть; если нет — честно говорится об этом. Сейчас в topic 4 последнее сообщение от 18.10, а метод отправки ни к чему не подключён.

## Требования (нормативные)

- [owner alignment №6–№9](../designs/rkb-owner-alignment-20261021.md): photo по умолчанию, high-resolution document только при необходимости по фактическому разрешению; оба locator, если нужны две формы; без произвольных 1280/2560.
- [`docs/operations/telegram-archive.md`](../operations/telegram-archive.md), раздел «Illustrations: photo and conditional high-resolution document»; [`docs/operations/illustration-pipeline.md`](../operations/illustration-pipeline.md) (topic 4, одна цепочка source → figure → evidence → crop → mirror).

## Что сделать

1. **Подключить** `NativeTelegramIllustrations` в существующем runtime (тот же арендованный клиент, `chat_id` и `topic_id` 4 из конфигурации) и вызывать `send_one` в существующем пути принятой иллюстрации (crop → mirror). Сначала фото. Затем по фактическим размерам исходника и вернувшегося фото (`needs_resolution_document`) — при необходимости второй вызов документом. Оба locator — в существующем хранилище операций. UNKNOWN — без слепого повтора.
2. **`illustration_fetch`**: один необязательный параметр качества (`standard` по умолчанию → фото; `original` → документ, если зарегистрирован, иначе фото с явной пометкой «оригинал не сохранён»). Без нового маршрута и без публичных ссылок.
3. **Перенос существующих иллюстраций** (сейчас в S3 или локальном зеркале — установи по коду) в topic 4 по тем же правилам: идемпотентно, locator к каждой. Запуск — Шкипер, после слияния.
4. Документация: отметить в `telegram-archive.md` и `illustration-pipeline.md`, что реализовано.

## Бюджет

Production ≤ 120 строк. Скрипт переноса ≤ 80 строк.

## Один различающий тест

С поддельным Telethon-клиентом: иллюстрация 800×600 при фото 1280×960 → только фото, один locator; иллюстрация 3000×2000 при фото 1280×853 → фото и документ, два locator. `illustration_fetch(id, quality='original')` отдаёт документ во втором случае и фото с пометкой в первом. На текущем main ни одного вызова `send_file`.
