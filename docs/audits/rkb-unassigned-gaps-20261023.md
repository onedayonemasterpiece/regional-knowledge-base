## 4. Решения, которые нужны (не владельцу — исполнителям)

- **Opus:** форма шага 1 упрощения (п.13). Продуктовая граница — без новых видов сообщений ради промежуточной формы.
- **dot:** по пп. 1–9 передать работу доступным исполнителям сейчас, если Launcher не даёт продолжить у Контура и Трассы. По каждому — одна строка STARTED в треде. По пп. 9–26 — назначить исполнителей или явно поставить в план с порядком.

## 5. Что не делать

- Не добавлять новых сервисов, этапов импорта, понятий («переимпорт», backfill), гейтов, хэшей кода в конфиге.
- Не строить отдельные версии историй для соцсетей: один текст истории на всех.
- Не добивать число историй выдумкой: справочный факт остаётся фактом.
- Старые принятые байты и ID не переписывать.
